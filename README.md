# Order Management Portal

Order Management Portal, ürün, tedarikçi, mağaza ve sipariş yönetimi için geliştirilen web tabanlı bir yönetim uygulamasıdır. İlk aşamada iç piyasa sipariş süreçlerini takip etmeyi hedefler. Uzun vadede yurtdışı siparişleri, ithalat/ihracat, sevkiyat, doküman yönetimi ve küçük işletmelere sunulabilecek SaaS yapısı desteklenecektir.

## Project Purpose

Bu projenin amacı sipariş operasyonlarını daha düzenli, takip edilebilir ve ölçeklenebilir hale getirmektir. Başlangıç sürümü statik HTML, CSS ve JavaScript ile geliştirilmektedir. İlerleyen fazlarda backend API, veritabanı, kullanıcı yönetimi ve deployment yapısı eklenecektir.

## Current Technology

- Frontend: HTML, CSS, JavaScript
- Backend: Planned with Node.js and Express
- Database: Planned with PostgreSQL
- Deployment: Planned with Vercel, Render, Supabase or Neon

## Setup

Bu aşamada proje statik dosyalardan oluşur. Çalıştırmak için `index.html` dosyasını tarayıcıda açmak yeterlidir.

Gelecekte Node.js backend eklendiğinde kurulum adımları ayrıca güncellenecektir.

## Development Notes

- Code language must be English.
- UI text can be Turkish.
- File names, variables, database tables, API endpoints and CSS class names must be English.
- Business data should not be permanently hardcoded.
- Reusable CSS classes and semantic HTML should be preferred.
